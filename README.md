# MentalHealth Web 🧘‍♂️✨

A premium, modern web application designed to revolutionize mental health service management. Built with cutting-edge technologies to provide a seamless experience for clinicians, hospital staff, and patients.

## 🚀 Key Features

-   **Clinical Intelligence**: Advanced dashboards for clinical data analysis and patient monitoring.
-   **Patient Directory**: Comprehensive management of patient records and medical history.
-   **Hospital Management**: Streamlined workflows for hospital staff and administrators.
-   **AI Screening**: (In Development) Intelligent screening tools to assist in mental health assessments.
-   **Real-time Communication**: Integrated socket communication for instant updates.
-   **Interactive Maps**: Patient and facility location tracking using Leaflet.

## 🛠️ Tech Stack

-   **Frontend**: React 19 + TypeScript + Vite
-   **Styling**: Tailwind CSS 4 + Framer Motion (for smooth animations)
-   **State Management**: Redux Toolkit
-   **Routing**: React Router 7
-   **Icons**: Lucide React
-   **Maps**: React Leaflet

## 📦 Getting Started

### Prerequisites

-   Node.js (Latest LTS recommended)
-   npm or yarn

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Gokulcsh-68/Mentalhealth_Web.git
    cd Mentalhealth_Web
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Environment Setup**:
    Create a `.env` file based on `.env.example` and fill in the required variables.

4.  **Run the development server**:
    ```bash
    npm run dev
    ```

## 🔄 Development Workflow

To keep your local `development` branch in sync with the upstream repository, follow these steps:

1.  **Fetch updates from upstream**:
    ```bash
    git fetch upstream
    ```

2.  **Checkout development branch**:
    ```bash
    git checkout development
    ```

3.  **Merge upstream changes**:
    ```bash
    git merge upstream/development
    ```

4.  **Push to your origin**:
    ```bash
    git push origin development
    ```
